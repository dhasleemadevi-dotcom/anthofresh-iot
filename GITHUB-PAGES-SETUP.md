# FreshTrace Bio — GitHub Pages

1. Extract this ZIP.
2. Copy ALL files in this folder into your GitHub repository root.
3. Make sure `index.html` is directly in the repository root.
4. Commit/push to `main`.
5. In GitHub: Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
6. Your site will be available at `https://YOUR-USERNAME.github.io/freshtrace-bio/`.

This is a static demo/prototype. Package demo data is stored in the browser/local app logic; a future Firebase connection is needed for shared cloud data and live ESP32 telemetry.
